\section{Frozen project decisions}

\begin{itemize}
\item The active scientific benchmark is the official $1^\circ$, $62\times62\times15$
  baroclinic double gyre.  Exact recovery of the paper's hidden $0.25^\circ$ numbers is
  outside the primary claim; qualitative trends are the reproduction target.
\item Model calendars use 360 days per year.  The time step is 1,200~s, or 72 steps per
  model day.
\item Standard trajectory production uses four MPI ranks.  Long runs are split into
  restart-safe jobs that fit the two-hour \texttt{short} partition.
\item S0--S2 share physics, grid, preprocessing, state definition, splits, and metrics.
  Only the prescribed forcing regime differs.
\item True \MITgcm{} adjoints are sealed test data.  They are excluded from training,
  early stopping, architecture selection, hyperparameter tuning, perturbation-scale
  selection, and loss selection.
\item All models must use the same immutable train/validation/test partition and
  training-only normalization statistics so architecture and loss comparisons remain
  interpretable.
\item Git stores source, configuration, tests, small manifests, and project-facing
  documentation.  Raw/reduced arrays, checkpoints, upstream clones, virtual
  environments, compiled trees, and scheduler logs remain external to Git.
\end{itemize}

\section{Baseline and forward-selection ladder}

\projectbox{blue}{lightblue}{%
\textbf{Decision added 21 July and revised 23 July 2026.}  Establish an adapted Bire
paper-architecture baseline, A0, before developing the modern NeuralOperator A--D
sequence.  This tests
whether the published architectural idea recovers the paper's qualitative wind and
forecast trends on the available tutorial configuration.  Keep B frozen, select C only
for forward fidelity, and add local-response supervision only in D.}

A0 is a controlled adaptation, not a claim of exact historical reproduction.  It keeps
the recognizable Bire choices---channel-diagonal/separable spectral convolution,
explicit pointwise channel mixing, three Fourier blocks, hidden width 128, positional
encoding, and one-step state loss.  Resolution-equivalent Fourier truncation uses 16
modes on the $62\times62$ grid.  The frozen A0 did not use the paper code's stride-8
coarse pretraining; this is a recorded adaptation, not an inferred reproduction.

Changes forced by this benchmark must be disclosed: 46 Markov-state channels
(centered U, V, temperature, and SSH), the $62\times62$ grid, ten production years per
regime, wind stress as an input, and a ten-day primary comparison horizon.  The obsolete
public repository will be used as architectural evidence, not executed unchanged.
Pressure is not a forgotten channel: evaluation contract v2 reconstructs \MITgcm{}
\texttt{PHIHYD} at levels 0, 7, and 14 from predicted temperature and SSH using the
configured linear EOS and exact finite-difference hydrostatic operator.  Its archived
S0 validation passes with \(3.89\times10^{-4}\ \mathrm{m^2\,s^{-2}}\) maximum error.

The comparison ladder is therefore:
\begin{center}\small
\textbf{Persistence / climatology}
$\longrightarrow$ \textbf{A0: adapted Bire}
$\longrightarrow$ \textbf{A: modern state-only}\\[3pt]
$\longrightarrow$ \textbf{B: forward losses}
$\longrightarrow$ \textbf{C: forward-selected}
$\longrightarrow$ \textbf{D: \AF{} response supervision}.
\end{center}
Every transition changes a declared element, making gains attributable rather than
confounding the dataset, architecture, and derivative-aware objective at once.

\section{How to update this tracker}

Update this document after a milestone changes state, a scientific decision changes,
or a material dataset/model artifact is created.  For each update:

\begin{enumerate}
\item advance the status date and change only milestones supported by durable evidence;
\item record Slurm job IDs, model-time duration, output counts, storage location, and
  validation result for every completed simulation;
\item add artifact paths and checksums where available; never treat a scratch pathname
  alone as an archival record;
\item record decision changes in both the relevant section and the change log;
\item regenerate \texttt{Project\_tracking.pdf} and check the LaTeX log for undefined
  references, overfull boxes, or missing files.
\end{enumerate}

Operational details and evolving status belong here.  Scientific definitions,
acceptance criteria, and the intended experimental design belong in
\texttt{AF\_FNO\_Project\_Plan.tex}; keep the two documents consistent without
duplicating extensive derivations.
